# Static mask cache prototype

16 real training frames: packed GT-support, observed child and valid-child masks were exactly equal to existing CPU definitions. Mean original static CPU preprocessing 0.2844 s/frame; warm cache load/unpack 0.0236 s/frame. Average compressed size 321994 bytes/frame. This is not an end-to-end speed benchmark and excludes GPU transfers, input read, Encoder and PTv3. Cache requires unchanged GT Parent support, geometry, input and closed targets; it is invalid for predicted supports or different augmentation. Full cache is independent and is not wired into current training. Dataset and input identities are recorded at construction; no per-step rehash is necessary if source data are frozen.

GPU3 follow-up: 12 real training frames exactly matched original parent IDs, input-only observed masks, valid masks, closed GT child labels, score placeholder and frozen T1 sampled features. First two frames are warmup. On remaining 10 frames, average full scene condition assembly wall time was 217.36 ms original vs 65.46 ms cached. This is one ordered pass (original then cached), no PTv3 forward/backward/optimizer; filesystem warming and order are confounders. Not a complete training step or paired multi-round estimate. Cache uses manifest identity and per-frame parent/target equality; source input files are assumed immutable at use time. Offline builder recorded each input SHA; runtime does not hash inputs on each step. Cache is valid only for GT support/zero negatives/no child bridge and corresponding frozen data, not predicted-parent inference. Current training remains unchanged.
